# 🚇 Metro Ticket Generation System — Built on ServiceNow
🎫 Digital Ticketing Made Simple, Fast, and Automated

A ServiceNow application built to streamline the entire metro ticketing process — from journey entry to fare calculation, payment, and generation of a QR-based digital ticket.

## 📌 About the Project

This application was created on the ServiceNow platform to replace manual metro ticket counters with a fully digital experience. Passengers can input their travel details, choose a boarding and destination station, get an automatically computed fare, complete payment, and receive a scannable QR ticket — all within the app.

The project showcases practical use of ServiceNow's app-building tools: custom tables, forms, automation logic, and digital ticket workflows.

## 🎯 Goals

- 🚇 Move the metro ticketing process from paper to digital
- 🎫 Issue tickets electronically without manual intervention
- 💰 Automatically compute travel fares
- 📱 Produce QR codes for each digital ticket
- 📋 Keep records of passengers and their tickets
- ⚙️ Minimize manual work in the ticketing flow
- ✅ Keep the booking experience quick and easy to use

## ✨ Core Capabilities

| Capability | What It Does |
|---|---|
| 👤 Passenger Info | Collects necessary passenger details |
| 🚇 Route Selection | Lets users pick start and end stations |
| 💰 Fare Engine | Works out ticket cost based on the chosen route |
| 💳 Payment Options | Offers a choice of payment modes |
| 🎫 Ticket Creation | Produces the digital ticket automatically |
| 📱 QR Generation | Attaches a unique QR code to each ticket |
| 📋 Ticket Records | Keeps a log of tickets and related data |
